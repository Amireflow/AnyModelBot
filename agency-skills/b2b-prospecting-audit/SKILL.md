# Protocole Prospection & Audit B2B

1. **Ciblage ICP prioritaire** : privilégier les PME B2B (immobilier, BTP, logistique, santé, e-commerce, services) ayant un besoin digital clair (site lent/obsolète, absence de prise de RDV, processus manuel).
2. **Faits vérifiés uniquement** : ne rapporter que les informations observables (URL exacte, code HTTP, HTTPS, viewport mobile, présence de méta-description, emails/téléphones publics). Ne jamais extrapoler le chiffre d'affaires ni inventer un contact.
3. **Déduplication stricte** : vérifier nom normalisé et domaine racine avant import afin d'éviter tout doublon CRM.
4. **Opportunité actionnable** : synthétiser chaque audit en 3 constats factuels + 1 angle de valeur concret pour le premier contact.
