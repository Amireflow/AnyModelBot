# Artisanat UI/UX Moderne

1. **Hiérarchie & respiration** : regrouper l'information par surfaces tonales cohérentes, titres courts, contrastes nets et valeurs numériques tabulaires.
2. **Mobile-first & accessibilité** : inclure `<html lang="fr">`, `<meta name="viewport">`, labels explicites, attributs `alt` sur les images, navigation clavier et grilles responsives sans débordement horizontal.
3. **États complets** : toujours prévoir l'état vide actionnable, l'état de chargement et l'affichage clair des erreurs.
4. **Cohérence visuelle** : utiliser des variables CSS centralisées (`:root`) pour couleurs, rayons, espacements et typographie.
