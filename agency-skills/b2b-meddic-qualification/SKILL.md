# Grille de Qualification B2B (MEDDIC / BANT)

1. **Preuves tracées** : chaque critère évalué (`met`, `partial`, `not_met`, `unknown`) doit s'appuyer sur une source ou un message client réel.
2. **Dimensions clés** :
   - *Need / Pain* : problème opérationnel chiffré ou frein commercial concret.
   - *Authority* : accès direct au décideur ou sponsor identifié.
   - *Budget* : adéquation avec le ticket minimum de l'agence (XOF/EUR).
   - *Timeline* : horizon de déploiement réaliste.
3. **Décision disciplinée** : recommander le passage en `qualified` uniquement si le score et la couverture documentaire respectent le profil ICP ; sinon lister explicitement les informations manquantes à collecter.
